# Cross-organization context

GitHub context forms one graph across organizations. Cross-repository references
use `owner/repository#number` or a full GitHub URL. Bare `#number` references stay
within this repository.

The reviewed map in `governance/cross-org-context.json` identifies adjacent
desired-state authorities and the shared governance Project. Parent Issues,
sub-issues and pull requests may reference any visible node in this graph.

GitHub Pages publishes sanitized static context. Changing observations and
Kubernetes output belong in Discussions, the runtime Wiki or observability.
